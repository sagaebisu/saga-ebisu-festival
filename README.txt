# 佐賀十日恵比須大祭 公式サイト

## 公開方法（いちばん簡単）
1. GitHubで新しいリポジトリを作る
2. `index.html` と `assets` フォルダをアップロード
3. Settings → Pages → Deploy from a branch → main / (root) を選ぶ
4. 表示されたURLを開く

## 更新方法
- 文章・リンク：GitHub上で `index.html` を編集
- 写真：`assets` フォルダへ新しい写真をアップロードし、必要に応じてHTML内のファイル名を変更
- 大きな修正：ChatGPTに「このサイトのここをこう直して」と依頼して、更新済みファイルを受け取る

## 注意
GitHub上で公開する場合、この構成ではリポジトリを公開設定にする運用を想定しています。
